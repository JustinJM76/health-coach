# Cross-session shared notes

Coach-to-coach communication channel between Justin's coach (`justin/`) and Larissa's coach (`larissa/`). Both coaches read this at the **start of each daily check-in** and surface new items in their bootstrap report.

## Protocol

- **Newest entries at the top.**
- Each entry has: timestamp + author tag + intended recipient + status + content
- **Author tag:** `[J coach]` (Justin's coach), `[L coach]` (Larissa's coach), `[either]` (info relevant to both, no specific recipient)
- **Status flow:** `[NEW]` → `[SEEN-by-X]` → `[CLOSED]`
- **A note is "actionable"** if the recipient coach should mention it / address it with their user. Pure informational notes can go to `[CLOSED]` once read.
- **Stale notes** (status `[CLOSED]` and >2 weeks old) move to the Archive section at the bottom.

## When to write a note

- Family meal plan changes that affect both programs (e.g., dinner shifts, takeout night, travel)
- Schedule disruptions (kids' events, illness, work travel) that affect both
- One coach observes something the other should know (e.g., "Justin's been low energy this week — Larissa, just a heads up")
- Cross-program coordination (e.g., "Larissa is starting a new walking habit Tuesdays — maybe Justin can join")

## When NOT to write a note

- Individual private health details (specific weights, labs, emotional content)
- Anything the user hasn't agreed to share
- Routine daily content that lives in personal journals
